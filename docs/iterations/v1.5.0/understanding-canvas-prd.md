## 1. 业务背景

### 1.1 为什么存在

Reflecta 帮助用户把学习、实践和对话后的有效思考沉淀成「理解」（Understanding）。随着理解越积越多，用户回看时遇到两个问题：

1. **理解是散乱的**：列表里的条目看不出逻辑关系——谁依赖谁、谁推导出谁、谁与谁矛盾。
2. **关系缺乏语义**：旧的知识图谱只显示"连了没有"，不显示"为什么连"；且关系是系统推断的，用户说不清也不认同。

用户真正需要的是：**亲手把理解摆出来，亲手标记它们之间的关系**，从而看清一个领域的心智结构——我理解了什么、哪些已经连成结构、哪些还是孤岛、下一步该补哪里。

### 1.2 服务什么场景

- **回看整理**：学完一个主题（如行为设计、交易心理、LLM Agent）后，把相关理解拖到一张画布上，摆出结构。
- **结构推导**：标记"B 依赖 A""C 由 A 推导而来"，让理解之间的逻辑链条显性化。
- **发现缺口**：看着画布发现哪些理解还是孤岛、哪个环节缺一块，决定下一步沉淀什么。
- **复用与关联**：同一张理解卡可以出现在多个画布（引用而非复制），一个理解在不同心智结构里各自发挥作用。

### 1.3 产品原则（不可走偏）

- **关系来自用户显式标记**：连线、标签、分组都由用户亲手完成；系统不自动推断关系。
- **用户是大脑**：画布是用户思考的载体，不是 AI 自动生成的图。
- **理解是引用**：画布上的理解卡引用理解库，不产生副本；被引理解删除后显示占位，不静默丢卡。

### 1.4 与双链（wiki-link / Connection）的关系定位

画布连线与现有双链**不重复，分层共存**：

|          | 双链（引用网）                                 | 画布连线（结构网）                       |
| -------- | ---------------------------------------------- | ---------------------------------------- |
| 语义     | 「我提到过 X」（弱引用）                       | 「X 在我的结构里处于什么位置」（强语义） |
| 形态     | 无向、无类型、无标签，正文 `[[u:id]]` 自动解析 | 有向、带标签、带样式，用户显式搭建       |
| 产生时机 | 写作时隐式产生                                 | 回看时显式搭建                           |
| 作用域   | 全局                                           | 画布局部                                 |
| 服务     | 回溯来源                                       | 看清结构                                 |

**调研结论（2026-08-11）**：社区对两者关系的处理有三种模式——分离（Obsidian：画布箭头纯视觉、与链接零互通）、统一（Scrintal：画布箭头与正文链接是同一关系）、部分统一（Heptabase：正文 backlink 可导入白板做视觉整理；Logseq：白板图形可链接块但双向同步有缺陷）。

**我们的选择：分层 + 素材互通（Heptabase 式）**，依据：

1. **不能统一**：画布连线是**画布局部**的——同一对理解在不同画布可标不同关系（如一个画布标「推导出」、另一个标「矛盾」）；统一成全局关系必然冲突。
2. **不能纯视觉分离**：我们的连线承载语义（有向 + 标签 + 样式），放弃语义等于放弃画布核心价值。
3. **素材互通，数据不互通**：
   - 从理解库拖入理解卡时，提示该理解已有的双链（参考现有引用决定如何连线，但连不连、标签是什么由用户定）。
   - 理解详情显示「该理解出现于哪些画布」（反向查询已有索引，见 M6-6）。
   - 正文引用不自动画线；画布连线不写回 `understanding_connections`（守住「关系来自用户显式标记」，也避免双向同步的维护泥潭）。

### 1.5 一句话定位

> 理解画布是一个无限画布：一张画布承载一个心智结构，卡片（理解、文本、图形）可自由摆放与连线，用户亲手标记"谁依赖谁、谁推导出谁"。

## 2. 功能模块

本版实现划分为 **7 个模块**，按职责与依赖关系组织：

```text
┌──────────────────────────────────────────────────────────────┐
│ 模块一：画布管理（入口）                                      │
│   画布列表：新建 / 重命名 / 删除，进入画布                    │
└──────────────┬───────────────────────────────────────────────┘
               ▼
┌──────────────────────────────────────────────────────────────┐
│ 模块二：画布工作区（主舞台）                                  │
│   工具栏 + 无限画布 + 左下控制 + 缩略图 + 搜索 + 演示 + 导出  │
└───────┬────────────────────────────────┬─────────────────────┘
        ▼                                ▼
┌────────────────────────┐  ┌─────────────────────────────────┐
│ 模块三：元素体系        │  │ 模块四：关系与连线              │
│ 理解卡 / 文本卡 / 图形  │  │ 有向连线 + 自由标签 + 吸附重路由│
│ / 组 / 画布引用         │  └─────────────────────────────────┘
└───────────┬────────────┘
            ▼
┌──────────────────────────────────────────────────────────────┐
│ 模块五：理解库面板（右侧单面板 · 库模式）                     │
│ 领域过滤 + 搜索 + 排序 + 理解列表 → 拖入画布                  │
└───────────┬──────────────────────────────────────────────────┘
            │ 互斥切换（同一面板槽位）
            ▼
┌──────────────────────────────────────────────────────────────┐
│ 模块六：理解详情联动（右侧单面板 · 详情模式）                 │
│ 点击理解卡 → 详情编辑 → 保存后画布卡片同步                    │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 模块七：编辑体验与数据（贯穿全部）                            │
│ 参考线 / 撤销重做 / 框选多选 / 删除 / 锁定 / 增量持久化      │
└──────────────────────────────────────────────────────────────┘
```

### 模块关系

- **模块一**是入口：用户从这里进入任意画布。
- **模块二**是主舞台：承载所有元素与连线的展示和操作。
- **模块三、模块四**是内容本体：元素是"有什么"，连线是"怎么关联"。
- **模块五、模块六**是内容的进出通道：理解从理解库拖入画布（模块五），点击卡片回到理解详情编辑（模块六）；两者共用右侧同一面板槽位，互斥切换。
- **模块七**是体验与数据底座：编辑体验能力贯穿模块二三四，持久化保证一切变更可恢复。

## 3. 功能详情

### 模块一：画布管理

| #    | 功能     | 产品要求                                                                           |
| ---- | -------- | ---------------------------------------------------------------------------------- |
| M1-1 | 画布列表 | 左侧列表展示全部画布，按最近更新时间排序；每项显示画布标题；支持新建、重命名、删除 |
| M1-2 | 新建画布 | 点击新建 → 生成默认标题（如「未命名画布」）→ 进入编辑；标题可在工作区顶部直接修改  |
| M1-3 | 删除画布 | 删除前弹确认框（明示"将删除画布及其全部内容"）；确认后画布及其元素、连线一并删除   |
| M1-4 | 空状态   | 无任何画布时显示引导（如「创建第一个画布，开始搭建你的心智结构」）                 |
| M1-5 | 进入画布 | 点击画布 → 进入工作区并加载该画布；退出后再次进入恢复上次的缩放与平移位置          |

### 模块二：画布工作区

| #    | 功能       | 产品要求                                                                                                     |
| ---- | ---------- | ------------------------------------------------------------------------------------------------------------ |
| M2-1 | 顶部工具栏 | 内容极简：画布标题（可编辑）、「理解库」按钮、文本卡图标、矩形图标、圆形图标                                 |
| M2-2 | 无限画布   | 自由二维空间，可无限平移；滚轮 / 触控板缩放（带惯性）；空处拖拽平移                                          |
| M2-3 | 背景网格   | 点状网格提供定位参考；不参与导出                                                                             |
| M2-4 | 左下控制   | 放大、缩小、适应视图（回到全部元素）、演示模式 四个按钮                                                      |
| M2-5 | 右下缩略图 | 常驻缩略图展示画布全局，随视口联动；可拖动/点击跳转视口（可选）                                              |
| M2-6 | 画布内搜索 | Cmd/Ctrl+F 唤起浮层；搜索范围：卡标题 / 正文、组名、连线标签；结果列表点击后平移缩放定位到对应元素；Esc 关闭 |
| M2-7 | 演示模式   | 进入后按「组」逐个走查：每步动画聚焦该组内容，prev / next / 退出控制；无组时退化为适应视图浏览               |
| M2-8 | 画布导出   | 导出当前画布为 PNG 图片（全内容），触发系统保存                                                              |

### 模块三：元素体系

**M3-A 理解卡**（引用理解库的 Understanding）

| #     | 功能     | 产品要求                                                                     |
| ----- | -------- | ---------------------------------------------------------------------------- |
| M3-A1 | 创建     | 从理解库面板拖入画布落点创建（详见模块五）                                   |
| M3-A2 | 展示     | 显示理解正文全文，不截断；不带领域标签 / 上下文数等附加信息                  |
| M3-A3 | 尺寸     | 卡片可自由调整宽高，正文随尺寸重排                                           |
| M3-A4 | 只读     | 画布上不可编辑内容；点击卡片 → 右侧单面板切换为详情模式（模块六）            |
| M3-A5 | 占位     | 被引理解被删除后，卡片显示「（已删除）」占位，仍可移动 / 连线 / 删除         |
| M3-A6 | 引用语义 | 同一理解可出现在多个画布（引用非副本）；理解内容更新后，画布卡片内容同步更新 |

**M3-B 文本卡**

| #     | 功能   | 产品要求                                                       |
| ----- | ------ | -------------------------------------------------------------- |
| M3-B1 | 创建   | 仅支持把工具栏「文本卡」图标拖入画布落点创建（不支持点击创建） |
| M3-B2 | 编辑   | 双击进入就地编辑；支持简单 Markdown（加粗、列表等）；失焦保存  |
| M3-B3 | 持久化 | 文本内容随画布持久化，重进画布完整还原                         |

**M3-C 图形元素**（矩形 / 圆形）

| #     | 功能     | 产品要求                                   |
| ----- | -------- | ------------------------------------------ |
| M3-C1 | 创建     | 工具栏「矩形」「圆形」图标拖入画布落点创建 |
| M3-C2 | 用途     | 用于画布内标记 / 圈注；本版无文字标签      |
| M3-C3 | 基本操作 | 可移动、调整尺寸、删除、选中               |

**M3-D 组**

| #     | 功能        | 产品要求                                                    |
| ----- | ----------- | ----------------------------------------------------------- |
| M3-D1 | 创建        | 工具栏「组」元素拖入画布创建空组容器                        |
| M3-D2 | 显式样式    | 组容器有可见边框与顶部标题栏，视觉上明确"这是一个组"        |
| M3-D3 | 组名        | 组名可编辑（双击标题栏或选中后编辑），持久化                |
| M3-D4 | 入组 / 出组 | 元素拖入组内即入组、拖出组外即出组；组内元素随组一起移动    |
| M3-D5 | 删除组      | 删除组 = 解组：组内元素保留并回到画布自由状态（不随组删除） |
| M3-D6 | 嵌套        | 组内可再放置元素（含其它组），层级不限                      |

**M3-E 画布引用**

| #     | 功能 | 产品要求                                                   |
| ----- | ---- | ---------------------------------------------------------- |
| M3-E1 | 创建 | 在画布上放置「画布引用」元素，选择目标画布（复用画布列表） |
| M3-E2 | 展示 | 显示目标画布标题                                           |
| M3-E3 | 跳转 | 点击引用元素 → 打开目标画布（替换当前画布）                |
| M3-E4 | 占位 | 目标画布被删除后，引用元素显示「（已删除）」占位           |

### 模块四：关系与连线

| #    | 功能         | 产品要求                                                                                                                                                                                                                         |
| ---- | ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| M4-1 | 创建连线     | 从卡片（或组）边缘拖出箭头到目标卡片，生成有向连线                                                                                                                                                                               |
| M4-2 | 方向         | 连线带方向箭头，从源指向目标；两端卡片均可作为源或目标                                                                                                                                                                           |
| M4-3 | 连线标签     | 双击连线就地编辑自由文本标签（如「推导出」「依赖」「矛盾于」）；标签随连线移动；持久化                                                                                                                                           |
| M4-4 | 吸附与重路由 | 拖动连线端点自动吸附元素边界；连线自动绕行避开遮挡元素                                                                                                                                                                           |
| M4-5 | 多连         | 同一对卡片允许多条不同标签的连线                                                                                                                                                                                                 |
| M4-6 | 删除         | 选中连线后 Delete / Backspace 删除                                                                                                                                                                                               |
| M4-7 | 连线样式     | 选中连线后可配置：**拐点类型**（直线 / 贝塞尔弧线 / 正交直角）、**线型**（实线 / 虚线 / 点线）、**颜色**（预设色板）、**粗细**（细 / 中 / 粗）、箭头（默认有向，可去掉）；可一键重置为默认样式（直线 + 实线 + 灰 + 中粗 + 箭头） | 样式生效、持久化、可重置 |

### 模块五：理解库面板（右侧单面板 · 库模式）

| #    | 功能     | 产品要求                                              |
| ---- | -------- | ----------------------------------------------------- |
| M5-1 | 打开     | 工具栏「理解库」按钮 → 右侧单面板切换为库模式         |
| M5-2 | 领域过滤 | 面板顶部支持领域（Domain）过滤，含"全部领域"选项      |
| M5-3 | 搜索     | 支持按关键词搜索理解                                  |

### 模块六：理解详情联动（右侧单面板 · 详情模式）

| #    | 功能     | 产品要求                                                                                        |
| ---- | -------- | ----------------------------------------------------------------------------------------------- |
| M6-1 | 打开详情 | 点击画布上的理解卡 → 右侧单面板切换为详情模式，展示该理解的详情与上下文（复用现有理解详情能力） |
| M6-2 | 编辑     | 在详情面板内编辑理解标题 / 正文 / 上下文                                                        |
| M6-3 | 同步     | 保存后，画布上引用该理解的卡片内容同步更新                                                      |
| M6-4 | 互斥     | 库模式与详情模式共用同一面板槽位，任一打开时另一自动关闭                                        |
| M6-5 | 关闭     | 关闭面板后回到画布全宽；画布上的卡片与连线位置不变                                              |
| M6-6 | 画布归属 | 理解详情中显示「该理解出现于哪些画布」（点击跳转对应画布），展示引用网与结构网的关联            |

### 模块七：编辑体验与数据

| #    | 功能        | 产品要求                                                                                                                                                |
| ---- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| M7-1 | 参考线对齐  | 拖动元素时出现与其它元素边缘 / 中心的对齐参考线，松手后位置落齐                                                                                         |
| M7-2 | 撤销 / 重做 | Cmd/Ctrl+Z 撤销、Cmd/Ctrl+Shift+Z 重做；覆盖位置、尺寸、增删、文本、标签、分组、锁定等全部变更；无工具栏按钮                                            |
| M7-3 | 框选多选    | 采用 **CAD 框选逻辑**：从左往右拖拽 → 仅完全包含在框内的元素被选中；从右往左拖拽 → 与框相交（部分接触）的元素即被选中；Shift 点选追加；多选后可整体移动 |
| M7-4 | 删除        | 选中元素 / 连线后 Delete / Backspace 删除；删除卡片时其连线一并删除                                                                                     |
| M7-5 | 元素锁定    | 选中元素后可锁定（防误拖）；锁定元素不可拖动、不可被框选移动，可解锁                                                                                    |
| M7-6 | 持久化      | 位置、尺寸、文本、标签、分组关系、锁定状态全部增量落库；缩放平移视口也保存，重进画布完整还原                                                            |

### 版本边界（本版不做）

- 多人协作、评论、投票（本地单机应用）。
- AI 自动生成内容 / 自动连线（违背"关系来自用户显式标记"）。
- 自由画笔 / 手绘。
- 画布导入导出除 PNG 外的格式（如 JSON 交换）。
