# 画布（X6）验收清单 v2.0.0

> 基线：React Flow 时代画布验收（8.1–8.9）。
> 现状：前端迁移至 AntV X6 3.1.8（`@antv/x6` + `@antv/x6-react-shape`）。
> 标注：`[保留]` 行为不变；`[修改]` 行为/入口/实现语义变化；`[新增]` 迁移后新承诺的能力；`[删除]` 不再提供（附替代）。
> 原则：Feature 只写用户可感知、可验收的产品承诺（见 `docs/references/technical/test-case-principles.md`）；本文是录入 acceptance Feature 文件前的评审底稿，最终按稳定 ID 落进 `apps/electron/e2e/acceptance/feature/canvas/*.feature`。

## 8.2 连线（边）

### 创建

- [保留] 从出桩（out）拖到入桩（in）建立有向边
- [保留] 同源同目标可建立多条平行边（connecting.allowMulti）
- [保留] 自环（source === target，allowLoop）
- [新增] 新连线默认带 canvasId 与默认样式（**createEdge 契约**，原先仅实现未显式验收）

### 样式（选中边后，底部边工具栏）

- [保留] 改颜色
- [修改] 改 routing —— 菜单仍为 曲线/直线/正交，语义映射到 X6 原语：**曲线 = connector `smooth`；直线 = connector `normal` + 无 router 中间点（X6 3.x 无 straight connector）；正交 = router `orth` + connector `rounded`**
- [保留] 改线型（实线 / 虚线 / 点线 → X6 `line.strokeDasharray`：虚线 5 5、点线 2 2）
- [保留] 改线宽（细 / 中 / 粗 → X6 `line.strokeWidth`：2 / 3 / 4）
- [修改] 改箭头 —— 选项对齐 X6 内建 marker 注册表：**箭头(classic)/方块(block)/圆点(circle)/菱形(diamond)/十字(cross)/椭圆(ellipse)/无(targetMarker null)**，用户只能选 X6 能渲染的
- [保留] 样式保存后重进保留

### 标签

- [保留] 选中边后编辑标签，提交后重进保留
- [保留] 清空标签回到无标签

### 删除

- [保留] 从边工具栏删除选中边
- [新增] 边样式变更后保持边选中（可连续调整颜色/形状/线型/线宽/箭头，不需重新选中）

- [保留] 多选（Shift/Ctrl + 点击，或 rubberband 框选）
- [修改] 空白处左键拖拽框选（rubberband）；**Space+左键拖拽 = 平移**（X6 panning 内置 spaceKey 判定）
- [保留] 多选后顶部出现选区工具条（打组 / 删除）

## 8.4 视口 / 网格

- [修改] ~~中键 / 滚轮平移画布~~ —— **中键拖拽 = 平移**（panning.eventTypes 含 mouseWheelDown）；**滚轮 = 缩放**（见下条）
- [删除] 滚轮平移 —— X6 中滚轮默认缩放（mousewheel 插件，zoomAtMousePosition）；平移由中键拖拽 / Space+拖拽承担，滚轮不再兼做平移
- [保留] 滚轮缩放（以鼠标位置为中心，zoomAtMousePosition:true）
- [保留] 左下缩放控件：放大 / 缩小 / 适应视图
- [修改] 节点拖动吸附到 10px 网格 —— X6 free-move 内建 `snapToGrid`（grid.size=10，无需手写吸附逻辑）
- [保留] 无已存视口时初始 fitView
- [保留] 有已存视口时恢复（保存后重进不挪动）
