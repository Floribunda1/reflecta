# v1.1.18

Patch release for Agent proposal feedback and chat composer ergonomics.

- Contextual Agent docks can jump into the full Agent thread.
- Long chat drafts keep the composer toolbar visible while the editor body scrolls.
- Approval tools stream candidate previews before the executable proposal is ready.
- Completed and rejected proposal cards collapse into compact receipts by default.
- Understanding update proposals no longer ask the Agent to fill `before`; Reflecta fills it from the current record.
- Agent write tool guidance documents wiki-link Markdown body format.
