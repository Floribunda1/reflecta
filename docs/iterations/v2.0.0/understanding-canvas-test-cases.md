# 理解画布 Test Case：原子操作与关键组合操作

> 日期：2026-08-18  
> 关联 PRD：[understanding-canvas-prd.md](./understanding-canvas-prd.md)

## 使用边界

本文描述的是画布层的原子操作，不是产品功能列表。

- 原子操作：一次画布手势、一次快捷键动作，或一次画布状态变化。
- 关键组合：多个原子操作按顺序执行，且前一步会改变后一步的前置条件、语义或结果。
- 每行一个 case；组合操作不做所有排列组合，只覆盖产品语义和数据不变量发生变化的路径。
- 理解库拖入理解卡、画布引用创建等跨面板落点操作，仍属于画布原子操作。
- 画布列表管理、理解详情内部编辑、Agent 工具协议不在本文范围内。

## 原子操作

### 画布加载与视口

- `@CV-ATOM-001`｜加载画布文档｜元素、连线和层级按文档创建。
- `@CV-ATOM-002`｜重新加载画布文档｜画布替换为最新文档。
- `@CV-ATOM-003`｜拖动画布空白区域｜视口平移，元素数据不变。
- `@CV-ATOM-004`｜滚轮缩放画布｜视口缩放，元素数据不变。
- `@CV-ATOM-005`｜点击放大｜视口放大。
- `@CV-ATOM-006`｜点击缩小｜视口缩小。
- `@CV-ATOM-007`｜点击适应视图｜所有元素进入可视范围。
- `@CV-ATOM-008`｜点击缩略图位置｜视口定位到对应区域。
- `@CV-ATOM-009`｜保存视口变化｜平移和缩放结果写入 viewport。
- `@CV-ATOM-010`｜恢复已保存视口｜画布以保存的缩放和平移状态显示。

### 元素拖入与创建

- `@CV-ATOM-011`｜工具栏拖入文本卡到空白处｜创建一个空文本卡。
- `@CV-ATOM-012`｜工具栏拖入矩形到空白处｜创建一个矩形元素。
- `@CV-ATOM-013`｜工具栏拖入圆形到空白处｜创建一个圆形元素。
- `@CV-ATOM-014`｜工具栏拖入组到空白处｜创建一个空组。
- `@CV-ATOM-015`｜理解库拖入理解卡到空白处｜创建一个理解卡引用。
- `@CV-ATOM-016`｜画布引用选择目标画布｜创建一个画布引用元素。
- `@CV-ATOM-017`｜元素拖入画布指定位置｜元素位置等于落点位置。
- `@CV-ATOM-018`｜元素拖入已有组区域｜元素被嵌入该组。
- `@CV-ATOM-019`｜拖拽未落在画布内｜不创建元素。
- `@CV-ATOM-020`｜只读画布执行拖入｜不创建元素。

### 元素选中与框选

- `@CV-ATOM-021`｜单击节点｜只选中该节点。
- `@CV-ATOM-022`｜单击连线｜只选中该连线。
- `@CV-ATOM-023`｜点击画布空白处｜取消当前选中状态。
- `@CV-ATOM-024`｜从左向右框选｜只选中完全位于框内的节点。
- `@CV-ATOM-025`｜从右向左框选｜选中与框相交的节点。
- `@CV-ATOM-026`｜Shift 框选｜将新节点追加到已有选区。
- `@CV-ATOM-027`｜框选连线区域｜不把连线错误识别为节点。
- `@CV-ATOM-028`｜只读画布选中元素｜不产生编辑选中状态回写。

### 元素移动与尺寸

- `@CV-ATOM-029`｜拖动普通节点｜节点位置更新。
- `@CV-ATOM-030`｜拖动组｜组位置更新。
- `@CV-ATOM-031`｜拖动组内节点｜节点在组内移动。
- `@CV-ATOM-032`｜拖动组内节点到组外｜节点解除父级关系。
- `@CV-ATOM-033`｜拖动组｜组内节点跟随移动。
- `@CV-ATOM-034`｜拖动元素经过对齐位置｜显示参考线并吸附对齐。
- `@CV-ATOM-035`｜调整理解卡尺寸｜宽高更新，正文重新排布。
- `@CV-ATOM-036`｜调整图形尺寸｜图形宽高更新。
- `@CV-ATOM-037`｜拖动锁定节点｜节点位置不变。
- `@CV-ATOM-038`｜框选后整体拖动｜所有选中节点同步移动。
- `@CV-ATOM-039`｜移动节点后回写文档｜文档保存最新 x/y。
- `@CV-ATOM-040`｜只读画布拖动节点｜节点位置不变。

### 文本、组名与连线标签编辑

- `@CV-ATOM-041`｜双击文本卡｜进入文本编辑状态。
- `@CV-ATOM-042`｜修改文本内容｜编辑框显示新内容。
- `@CV-ATOM-043`｜文本编辑失焦｜新内容写回节点数据。
- `@CV-ATOM-044`｜文本内容为空并失焦｜节点保留空文本。
- `@CV-ATOM-045`｜输入简单 Markdown｜预览按 Markdown 展示。
- `@CV-ATOM-046`｜双击组名｜进入组名编辑状态。
- `@CV-ATOM-047`｜修改组名并确认｜组名写回组数据。
- `@CV-ATOM-048`｜组名编辑失焦｜组名保存。
- `@CV-ATOM-049`｜双击连线｜打开连线标签编辑器。
- `@CV-ATOM-050`｜修改连线标签并确认｜标签写回连线数据。
- `@CV-ATOM-051`｜清空连线标签｜连线不再显示标签。
- `@CV-ATOM-052`｜只读画布编辑文本或组名｜内容不发生变化。

### 组与层级

- `@CV-ATOM-053`｜创建空组｜组没有子元素。
- `@CV-ATOM-054`｜元素进入组｜元素 parentId 指向该组。
- `@CV-ATOM-055`｜元素离开组｜元素 parentId 变为空。
- `@CV-ATOM-056`｜组内嵌套组｜子组成为外层组的子元素。
- `@CV-ATOM-057`｜解除组｜组被移除，子元素保留。
- `@CV-ATOM-058`｜删除组｜组及组内元素全部被移除。
- `@CV-ATOM-059`｜删除组内元素｜只删除该元素及其相关连线。
- `@CV-ATOM-060`｜右键打开组菜单｜显示解除组和删除组操作。
- `@CV-ATOM-061`｜组层级回写文档｜parentId 与当前层级一致。
- `@CV-ATOM-062`｜组层级重新加载｜层级关系正确恢复。

### 连线创建与连接

- `@CV-ATOM-063`｜从节点端口拖到另一节点｜创建一条连线。
- `@CV-ATOM-064`｜从 A 拖到 B｜连线 source 为 A、target 为 B。
- `@CV-ATOM-065`｜从 B 拖到 A｜连线方向反向创建。
- `@CV-ATOM-066`｜端口拖动到元素边界｜端点吸附到元素边界。
- `@CV-ATOM-067`｜端口拖动到空白处｜不创建连线。
- `@CV-ATOM-068`｜端口拖回自身｜不创建自环连线。
- `@CV-ATOM-069`｜端口拖到已有连线｜不创建连线。
- `@CV-ATOM-070`｜同一对节点重复连线｜允许创建多条连线。
- `@CV-ATOM-071`｜拖动已有连线端点｜连线重新连接到新节点。
- `@CV-ATOM-072`｜节点移动经过连线路径｜连线重新计算路径。
- `@CV-ATOM-073`｜存在遮挡元素时创建连线｜连线按路由避开遮挡。

### 连线样式

- `@CV-ATOM-074`｜选中连线｜打开连线样式面板。
- `@CV-ATOM-075`｜设置直线路由｜连线使用直线路径。
- `@CV-ATOM-076`｜设置弧线路由｜连线使用弧线路径。
- `@CV-ATOM-077`｜设置正交路由｜连线使用正交路径。
- `@CV-ATOM-078`｜设置实线｜连线显示实线。
- `@CV-ATOM-079`｜设置虚线｜连线显示虚线。
- `@CV-ATOM-080`｜设置点线｜连线显示点线。
- `@CV-ATOM-081`｜设置颜色｜连线使用选定颜色。
- `@CV-ATOM-082`｜设置粗细｜连线使用选定宽度。
- `@CV-ATOM-083`｜设置箭头｜目标端显示箭头。
- `@CV-ATOM-084`｜关闭箭头｜目标端不显示箭头。
- `@CV-ATOM-085`｜重置连线样式｜恢复默认路由、线型、颜色、粗细和箭头。
- `@CV-ATOM-086`｜样式变化回写文档｜连线 style 与当前显示一致。

### 删除、锁定与历史

- `@CV-ATOM-087`｜Delete 删除选中节点｜节点被移除。
- `@CV-ATOM-088`｜Backspace 删除选中节点｜节点被移除。
- `@CV-ATOM-089`｜删除节点｜节点关联的连线同步移除。
- `@CV-ATOM-090`｜Delete 删除选中连线｜连线被移除。
- `@CV-ATOM-091`｜删除组｜组内元素和相关连线级联移除。
- `@CV-ATOM-092`｜删除多选节点｜所有选中节点被移除。
- `@CV-ATOM-093`｜输入框聚焦时按 Delete｜输入内容不被误删。
- `@CV-ATOM-094`｜只读画布执行删除｜画布内容不变。
- `@CV-ATOM-095`｜右键锁定节点｜节点 locked 状态变为 true。
- `@CV-ATOM-096`｜再次右键解锁节点｜节点恢复可编辑。
- `@CV-ATOM-097`｜撤销创建或删除｜元素恢复到上一个状态。
- `@CV-ATOM-098`｜撤销移动或缩放｜几何状态恢复。
- `@CV-ATOM-099`｜撤销文本或标签编辑｜内容恢复。
- `@CV-ATOM-100`｜撤销分组或解除组｜层级关系恢复。
- `@CV-ATOM-101`｜撤销锁定或解锁｜锁定状态恢复。
- `@CV-ATOM-102`｜重做已撤销操作｜操作重新生效。

### 文档与事件桥

- `@CV-ATOM-103`｜节点新增事件｜文档包含新节点。
- `@CV-ATOM-104`｜节点移动事件｜文档 x/y 与画布一致。
- `@CV-ATOM-105`｜节点缩放事件｜文档 width/height 与画布一致。
- `@CV-ATOM-106`｜节点内容变化事件｜文档 props 与画布一致。
- `@CV-ATOM-107`｜节点入组事件｜文档 parentId 与画布一致。
- `@CV-ATOM-108`｜连线创建事件｜文档 source/target 与画布一致。
- `@CV-ATOM-109`｜连线标签变化事件｜文档 label 与画布一致。
- `@CV-ATOM-110`｜连线样式变化事件｜文档 style 与画布一致。
- `@CV-ATOM-111`｜节点删除事件｜文档不存在已删除节点和悬空连线。
- `@CV-ATOM-112`｜只读画布交互事件｜不触发编辑文档回写。

## 关键组合操作

- `@CV-COMB-001`｜创建文本卡→编辑内容→失焦→重新加载｜文本完整保留。
- `@CV-COMB-002`｜创建图形→移动→调整尺寸→删除｜每一步状态正确且删除后无残留。
- `@CV-COMB-003`｜创建组→拖入文本卡→改名→移动组｜文本卡跟随组移动且组名保留。
- `@CV-COMB-004`｜创建组→拖入元素→解除组→重新加载｜元素保留且恢复自由状态。
- `@CV-COMB-005`｜嵌套组→删除外层组｜所有嵌套元素和相关连线级联删除。
- `@CV-COMB-006`｜创建元素 A/B→A 连向 B→删除 A｜B 保留且连线被删除。
- `@CV-COMB-007`｜创建连线→编辑标签→修改样式→重新加载｜方向、标签和样式全部保留。
- `@CV-COMB-008`｜创建多条连线→删除其中一条｜其余连线不受影响。
- `@CV-COMB-009`｜创建连线→重连目标→编辑标签｜新目标和标签均正确保存。
- `@CV-COMB-010`｜创建组→组内元素连线→删除组｜组、元素和连线全部删除。
- `@CV-COMB-011`｜框选多个元素→整体移动→重新加载｜所有元素的新位置保留。
- `@CV-COMB-012`｜锁定元素→框选移动→解锁→再次移动｜锁定期间不移动，解锁后可移动。
- `@CV-COMB-013`｜创建元素→移动→调整尺寸→编辑→撤销/重做｜每种变更都可正确撤销和重做。
- `@CV-COMB-014`｜创建元素→缩放/平移视口→离开→重新进入｜内容和视口均还原。
- `@CV-COMB-015`｜搜索元素→点击结果→定位→关闭搜索｜元素被定位且搜索浮层关闭。
- `@CV-COMB-016`｜创建多个组→进入演示→前进/后退→退出｜各组按顺序聚焦且退出后恢复普通视图。
- `@CV-COMB-017`｜打开理解库→搜索/过滤→拖入理解卡→关闭面板｜理解卡创建成功且画布恢复全宽。
- `@CV-COMB-018`｜理解卡被删除→移动→连线→删除｜已删除占位卡仍具备完整元素操作能力。
- `@CV-COMB-019`｜创建画布引用→打开目标画布→删除目标画布→返回原画布｜引用卡变为已删除占位。
- `@CV-COMB-020`｜节点删除→撤销→重做｜节点、相关连线和文档状态保持一致。
