# v1.1.22 — Direct Entity Citation Trial

本版本在独立分支试验 Agent 正文直接引用 Reflecta 稳定实体 ID：

```text
[[u:<entity-id>]]
[[c:<entity-id>]]
[[d:<entity-id>]]
```

试验目标不是立即替换生产 numbered citation，而是验证这套协议在真实模型输出、工具调用、流式渲染、历史恢复和标题更新场景中是否足够可靠。

设计与测试计划见 [Agent Direct Entity Citation Trial Plan](agent-direct-entity-citation-trial-plan.md)。
