# v1.2.0 — 知识漫步

本版本将低频且能力分散的 Contemplate 页面收回 Capture，把产品顶层信息架构简化为 Capture + Agent。

知识漫步的当前产品方向是：让用户打开一个领域，反复翻阅自己已经形成的 Understanding 及其 Context，直到自己对这个领域已经知道什么，越来越熟悉、清晰和深入。

首版瀑布流与全局图谱已经完成实现验证，但它们不再被视为产品答案。改版将完整删除这两套实现，重新构建一张按当前领域展开的连续阅读页：用户通过普通滚动慢读或快扫完整 Understanding，点击内容时再进入现有详情与 Context。页面不依赖随机逻辑、AI 阅读路径、复习任务或量化激励。
